# Brand Studio — consultation & AI automation pricing (offer draft)

**Site:** https://mybrandstudio.club  
**Repo:** GeorgieXRPL/My-Brand-Studio  
**Purpose:** Reference rate card so Gatspy can fold bands into live packages / offers.  
**Currency:** NZD + GST unless noted. Market comps below are 2025–26 public bands (USD/NZ), not guarantees.

Product truth: live bookable studio, same-day sketch (book before 10:00 NZ), done-for-you brand sites + optional AI/automation. Not a free builder. Not a waitlist.

## Suggested Brand Studio ladder (use on offers)

| Offer | Price (NZD + GST) | What they get | Notes |
|-------|-------------------|---------------|-------|
| Qualify call | Free (15–20 min) | Fit check, sketch slot or next step | Keep as lead magnet; before-10am same-day sketch lane |
| Automation Consult | **$299–$499** | 45–60 min + 1-page plan | Advice-only; no build |
| Systems discovery | **$1,500–$3,500** fixed | Map of workflows, priority automations, written quote | Credit **50–100%** toward build within 30–60 days |
| Brand site (sketch → ship) | Existing studio packages | Same-day concept → live brand site | Anchor against NZ AI-web comps below |
| Website + light AI automation | **$4,500–$12,000** | Site + booking/chat/follow-up style automations | Aligns with NZ “site + AI” packages |
| Custom AI / ops systems | **From $8,000** (scoped) | CRM/Xero/calendar workflows, internal tools | Fixed quote after discovery |
| Care (hosting / small edits) | **$149–$899 / mo** | Site care, light tweaks | Not full AI ops |
| Automation retainer | **$2,000–$5,000 / mo** | Monitoring, tuning, next workflow | Only after something is live |

**Default commercial shape:** free qualify → fixed discovery (optional) → fixed build → optional retainer. Prefer **fixed scope** over open-ended hourly for SMBs.

## Market comps (research summary)

### Consultation / discovery
- Free 30–60 min discovery: common industry practice
- Paid strategy/audit: **US$1,000–$5,000** (sometimes **$10,000+**)
- Formal website discovery: **US$3,000–$15,000** (~5–10% of build budget)
- Boutique fixed discovery: from ~**US$3,500**

### Hourly AI automation consulting
| Tier | USD/hr | Rough NZD/hr (×1.65 ballpark) |
|------|--------|-------------------------------|
| Freelance / Upwork | $35–$150 | ~$60–$250 |
| SMB boutique / independent | **$150–$350** | **~$250–$580** |
| NZ independents (local guides) | — | **NZ$150–$350** |
| Big 4 / strategy | $300–$900 | Enterprise only |

### Project builds
- SMB single automation: **US$5k–$25k** (often **$10–15k**)
- Broader multi-workflow: **US$15k–$75k**
- NZ published packages (examples):
  - Lead-capture site: ~**NZ$990–$3,000**
  - Website + AI automation: from ~**NZ$4,490**
  - Custom AI systems: from ~**NZ$7,990**
  - Agentic site tiers: ~**NZ$2,000 / $8,500 / $20,000+**

### Retainers
- Light care: **US$400–$2,000 / mo**
- SMB AI ops: **US$2,000–$8,000 / mo** (NZ guides often **NZ$4,000–$8,000 / mo**)
- Fractional embedded team: **US$8,500+ / mo**
